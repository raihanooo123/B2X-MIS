# B2X User Manual

This directory contains task-based chapters for people operating B2X. Chapters describe the application as implemented, not every capability proposed in the technical specifications. Add new chapters here as other modules become usable; keep each chapter independently readable and update its review date when behaviour changes.

| Chapter | Audience | Status |
|---|---|---|
| [01 - Catalogue setup and warehouse operations](01-catalogue-and-warehouse.md) | Catalogue administrators and warehouse staff | Working draft, reviewed 2026-09-26 |

The technical specifications in `docs/` define intended behaviour. This manual explains how to perform the currently available work. Where a prerequisite has no user interface yet, the relevant chapter says so.
